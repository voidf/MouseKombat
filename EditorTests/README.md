# 编辑器工作流与验证

## 日常操作

- 默认左栏宽 440 px、时间轴高 180 px，主视图吸收剩余空间。拖动分隔条后会记住布局；右上角“重置布局”恢复默认值。
- 将 PNG 拖到主视图或图层页空白处，没有图层也会自动创建。拖到已有图层卡片会替换图片并保留偏移。
- 多张 PNG 按文件名自然顺序（1、2、10）从当前帧依次导入，不足自动补帧。主视图选中了图层时替换该图层，否则新增图层；新增帧沿用根坐标和图层偏移，不复制受击盒或特效。
- 图层页和受击盒页都有“沿用上一帧”、复制、粘贴及“来源帧”直接覆盖，不需要先跳到来源帧。帧号与时间轴一致，从 0 开始。
- `Ctrl+Shift+V` 沿用上一帧，`Ctrl+C` / `Ctrl+V` 复制、粘贴当前页的数据。`←` / `→` 切帧。编辑文本框时保留正常的文本操作。
- 在时间轴拖选多帧后，使用“覆盖选中帧”或“粘贴到选中帧”批量操作；整个批次只需一次 `Ctrl+Z` 撤销。没有多选时操作当前帧。
- 图层页的“仅复制偏移”按 Z 对应图层，保留图片和未匹配图层。图层图片路径属于当前角色，图层剪贴板不可跨角色粘贴；受击盒剪贴板独立，不受该限制。
- 受击盒页可编辑中心 X/Y、半宽、半高，也可以把基础盒展开为本帧的可编辑盒。空受击盒列表仍表示使用角色基础盒，不表示无敌；复制空列表会恢复基础盒继承。
- 图层与受击盒操作互不影响，也不改已有帧的根坐标、特效、伤害或打击盒。导入资源仍遵循原有同名文件覆盖规则；撤销恢复帧配置，不回滚磁盘上的资源文件。

## 自动验证

```powershell
dotnet build MouseKombat.csproj
dotnet run --project MouseKombat.Sim.Tests
& '<Godot .NET executable>' --headless --path . res://EditorTests/SmokeTests.tscn
```

纯数据测试覆盖深拷贝、动画/受击盒隔离、仅偏移复制、空列表和自然排序。Godot 场景测试使用临时角色目录，验证真实控件布局、窗口缩放、PNG 拖放分发、序列帧导入、快捷键、批量覆盖和撤销重做，不保存或覆盖仓库里的角色数据。
