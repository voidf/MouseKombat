# 编辑器工作流与验证

## 日常操作

- 默认左栏宽 440 px、时间轴高 180 px，主视图吸收剩余空间。拖动分隔条后会记住布局；右上角“重置布局”恢复默认值。
- 将 PNG 拖到主视图或图层页空白处，没有图层也会自动创建。拖到已有图层卡片会替换图片并保留偏移。
- 多张 PNG 按文件名自然顺序（1、2、10）从当前帧依次导入，不足自动补帧。主视图选中了图层时替换该图层，否则新增图层；新增帧沿用根坐标和图层偏移，不复制受击盒或特效。
- 图层页和受击盒页都有“沿用上一帧”、复制、粘贴及“来源帧”直接覆盖，不需要先跳到来源帧。帧号与时间轴一致，从 0 开始。
- `Ctrl+Shift+V` 沿用上一帧，`Ctrl+C` / `Ctrl+V` 复制、粘贴当前页的数据。`←` / `→` 切帧。编辑文本框时保留正常的文本操作。
- 在时间轴拖选多帧后，使用“覆盖选中帧”或“粘贴到选中帧”批量操作；整个批次只需一次 `Ctrl+Z` 撤销。没有多选时操作当前帧。
- 图层页的“仅复制偏移”按 Z 对应图层，保留图片和未匹配图层。图层图片路径属于当前角色，图层剪贴板不可跨角色粘贴；受击盒剪贴板独立，不受该限制。
- 受击盒页可编辑中心 X/Y、半宽、半高，也可以把基础盒展开为本帧的可编辑盒。空受击盒列表仍表示使用角色基础盒，不表示无敌；复制空列表会恢复基础盒继承。
- 图层与受击盒操作互不影响，也不改已有帧的根坐标、特效、伤害或打击盒。

## 时间轴插帧与移动

- 在目标帧右键按下、松开，菜单提供“在此帧左侧/右侧插入空白帧”。空白帧不复制图层、受击盒和特效，根坐标沿用相邻帧，避免额外的根位移跳变。
- 插帧会顺延后续的抬手/生效/收招区间、可行动帧、飞行道具生成帧、投技绑定与伤害事件；在已有区间内部插帧会延长该区间。
- 左键刷选区间后，在选区内按住右键，拖到目标格的左半/右半，松开后将选区整体插到目标帧的左侧/右侧。其它帧顺移，不覆盖目标帧，选区内原有顺序不变。
- 移动的是完整帧（图层、受击盒、根坐标、特效与本帧伤害）。动作级出招区间和事件仍保留在原来的时间轴帧号，便于在既定判定节奏上重新排动画；需要改变判定节奏时再编辑对应参数。
- 拖到末尾的“+”格可移动到最后；拖动到视图边缘会自动横向滚动。放回选区或放到时间轴外不会修改；`Esc` 取消本次拖动。同一格内按下、松开仍视为右键菜单。
- 插帧、整段移动各产生一次撤销记录；`Ctrl+Z` / `Ctrl+Y` 可撤销、重做。

## 图片资源隔离

- 所有 PNG 导入入口（空白处、主视图、图层卡片、替换图片按钮）都生成新的 `images/角色_动作_0000.png` 文件，不信任源文件名，不覆盖已存在的资源。
- 编号使用当前文件与所有动作图片引用中的最小空闲非负 ID（MEX），不额外保存计数器，也不绑定时间轴帧号。移动、插帧、改动作名都不会重命名既有图片；改名后的新导入使用新的动作名前缀。
- 替换图片仅修改当前图层的引用。其它帧或动作即使共享旧图片，也不会一起变化；撤销后旧引用和旧像素都仍然存在。序列帧仍按原始文件名自然排序，再分配新资源名。
- 旧资源不会被自动迁移或删除，以免破坏既有引用与撤销记录。已经被旧版同名覆盖污染的图片需要从原始 PNG 重新导入，不能凭被覆盖后的文件恢复像素。

## 自动验证

```powershell
dotnet build MouseKombat.csproj
dotnet run --project MouseKombat.Sim.Tests
& '<Godot .NET executable>' --headless --path . res://EditorTests/SmokeTests.tscn
```

纯数据测试覆盖深拷贝、动画/受击盒隔离、仅偏移复制、自然排序、插帧时序顺延、MEX 命名，以及最多 8 帧的全部选区与插入位置组合。Godot 场景测试使用临时角色目录，验证真实控件布局、PNG 导入隔离、共享图片替换、右键按下/拖动/松开、插帧菜单、边界取消和撤销重做，不保存或覆盖仓库里的角色数据。
